# Activity 5: Stacks and Queues

This Python activity demonstrates stacks and queues using arrays and linked lists.

## Files
- `array_structures.py` — ArrayStack and circular ArrayQueue.
- `linked_structures.py` — LinkedStack and LinkedQueue.
- `main.py` — Menu-driven program, balanced-parentheses checker, and print queue simulation.
- `analysis.md` — Analysis of the data structures.

## How to Run
Install Python 3, open a terminal in this folder, and run:

```bash
python main.py
```

Array-based structures have a fixed capacity. Linked-list structures grow as needed. The program handles stack and queue underflow and array overflow errors.
